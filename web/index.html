imigraph live: Brownian motion in a box, imitated by a graph

The same Python package as the tests, running in your browser through Pyodide (Python 3.14 in WebAssembly). The first run downloads Pyodide, numpy and scipy (about 15 MB) and may take half a minute.

D = a² / (4τ) for both systems. Smaller runs finish faster in the browser.

2. The rule, explained

The space is a lattice graph; boundary nodes keep self-loops for the neighbours they lack (the walls). Each particle is a walker node attached by one edge. The rule {w,s}, {s,s'} → {w,s'}, {s,s'} picks, for every walker at once, one of the four edges at its node uniformly at random and moves the walker edge along it; a self-loop means the walker stays. One application moves a walker by a or 0, so D = a² / (4τ).

One walker on a 5×5 space; each application in four phases (state, match, choose, rewrite).

5. Energy, momentum, entropy, walls, spreading

Energy and momentum are measured from every simulation step and averaged per recording interval; the ensemble values stay the same (temperature 2D/dt, momentum zero within its expected fluctuation) in both systems. The occupancy entropy rises towards ln(bins), on average but not monotonically.
