Reference. $particles independent particles start at the centre of the box and diffuse with coefficient D; walls reflect. Integrated with Euler–Maruyama, x += sqrt(2 D dt) ξ.

Graph system. The space is a $lattice_size×$lattice_size square lattice with spacing a (boundary nodes carry self-loops so every node has four edges). Each particle is a walker node attached to one space node by a single edge. Every step the rule {w,s}, {s,s'} → {w,s'}, {s,s'} moves each walker edge along a uniformly random edge of its anchor. This is a random walk with D = a² / (4τ), which is the D the reference is run with.

Projection. A walker is placed on the coordinates of its node; for the distribution tests it is placed at a fixed random point inside the node's cell (resolution a).
