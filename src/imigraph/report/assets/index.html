imigraph reports

Result pages of python -m imigraph report, gas-report and playground-report (and pages saved from the GUI), newest first. A page is written for bigger changes (a new system, rule, check or metric) and older pages are kept, so results of earlier versions of the code stay comparable. A rule_editor_*.html page is the browser GUI itself (gui-page): open it to edit and test rules; it runs Python in the browser and needs the network once to download Pyodide.
