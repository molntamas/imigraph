1. The rules

Each rule is an edge rewrite in the notation {w,s}, {s,t} → {w,t}, {s,t}: a walker edge plus a chain of site edges on the left, the walker re-attached to a site of the chain on the right. The pattern drawings show the variables as nodes (sites grey, walkers red) and the edges of each side. Direction weights (+x, −x, +y, −y) and the self-loop policy of every rule are in the choice and matches columns. The built-in rules of hyperedge walkers (Stream, Reflect) and the Collide rule of the hpp collisions are listed the same way. Walker model of this run: $walker_model, collisions: $collisions, overlapping matches: $overlaps.

5. Reproduce

The session as the GUI exports it. Save it as session.json and run python -m imigraph playground-report --request-file session.json --label <name>, or import it in the GUI.
